# Plan: character card that never dead-ends

For: a Sonnet session on branch `claude/sonnet-dictionary-upgrade-0465eb`. Read `CLAUDE.md` first (copyright, commit identity, proxy, token budget).

## The problem
The 字 card (`src/views/charsheet.js`, `openChar`) only knows lesson characters (`CHARINFO` = `src/data/charinfo.gen.json`,
built by `scripts/gen-charinfo.mjs` for lesson chars only). A part chip is tappable only if the part is itself a lesson
character (`chip(x, open)` checks `CHARINFO[x.c]`). So in 换 = 扌 + 奂, tapping 奂 just speaks it: the trail stops.
And nothing tells the learner *what kind of thing* a part is: a radical side-form (扌), a rare character that only matters
as a sound part (奂), a common character worth learning (央), or a bare shape (⺈).
奂's gloss "numerous" is also unhelpful: in 换 it is there for its sound, not its meaning.

## What already exists (reuse, don't rebuild)
- `public/dict/chars.json` (generated by `scripts/gen-dict.mjs`, ~9.5k chars from Make Me a Hanzi):
  `{ c: [py, en, radical, dec, type, phonetic, hint] }`. Lazy-loaded by `charParts(c)` in `src/lib/dict.js`
  (already used by the Notebook word page). 奂 → `["huàn","numerous","大","⿱⺈央",…]`, 央 → `⿻冂大`.
- `lookup(word)` in `src/lib/dict.js`: book words, then CC-CEDICT shards.
- `src/data/radicals-core.json`: 81 radicals with `r`, `full`, `variants` (扌 → full 手). Radical pages at `#/radical/<r>`.
- `RADICALS` (`src/data/radicals.json`): names for 183 radical forms.
- `wordsWith(c)`, `bookOf`, `LESSONS` for "is it in my books".

## Goal (what the owner sees)
1. **Every part is tappable**, at any depth: 换 → 奂 → 央 → 大. Stops only at a basic shape, which says so.
2. **A trail at the top of the card**: `换 › 奂 › 央`, each step tappable; Back (and `Esc`) goes up one step, not out.
3. **A verdict line under the title**, one of five, answering "do I need to learn this?":
   - **In your books**: "You know it" / "Comes in HSK 2 · Lesson 5". (lesson char)
   - **Common character**: "Common on its own: worth learning." Plus 2–3 everyday words from CC-CEDICT.
   - **Mostly a part**: "Rare on its own. Learn it as a part: it gives the sound *huan* in 换 唤 焕 涣."
   - **Radical form**: "Side form of 手 (hand). Never written alone; learn the shape." Link to `#/radical/扌` when it is a core radical.
   - **Basic shape**: "A basic shape, not a character. The trail ends here."
4. **Sound family** section for a phonetic part: all characters whose `phonetic` is this part, from `chars.json`,
   common ones first, the ones in your books marked. (奂: 换 唤 焕 涣 痪.) This is the real reason to know 奂.
5. **Role tags on part chips**: small "meaning" / "sound" label under the chip when the etymology says so. A sound part
   shows its pinyin, and its meaning only in muted text (no more 奂 = "numerous" as if it mattered).
6. Radical section: replace "characters with 扌 are often about hand" boilerplate with a link to the radical page when
   one exists; keep the sentence otherwise.

## Dictionary upgrade (the owner asked for this too)
7. **Better meanings**: for any character, show up to 3 senses from CC-CEDICT (`lookup`) under the title, not only
   Make Me a Hanzi's first word. Skip "surname X" and "variant of X" senses when there are others.
8. **Search the whole dictionary**: today `#/search` (`src/views/search.js`) only finds words from the books.
   When the query has Chinese characters, also show results from CC-CEDICT (`lookup`) under a quiet heading
   "Not in your books", each with pinyin and meaning, tap to hear, a single character tap to open its card, and
   a "Save to Notebook" button if the Notebook already has an add function (reuse it, don't write a new one).
   Pinyin and English search stay book-only for now (a full index would be too big).

## How to decide "common" (no new downloads)
Use a proxy built at gen time in `scripts/gen-dict.mjs`: number of CC-CEDICT words that contain the character
(excluding surnames/variant entries if easy). Store it as an 8th field in `chars.json` (a rank or a 0–3 tier, keep it
small). Calibrate the threshold so roughly 3,000 characters count as common, then check this sample by hand and adjust:
common: 央 换 马 口 手 大 交 反; rare/part: 奂 曷 娄 尼(borderline, fine either way) 巴(common). Shape: ⺈ 丷 冂.
If the proxy gets more than 2 of the sample wrong, stop and tell the owner instead of adding a frequency list.

Classification order (first match wins): lesson char → radical side-form (in `radicals-core` variants, or in `RADICALS`
and not in `chars.json` with a pinyin) → no pinyin/no entry → basic shape → common tier → mostly a part.
Put this in one small pure module, e.g. `src/lib/char-kind.js`, with a unit test over the sample above.

## Data changes
- `scripts/gen-dict.mjs`: add the tier field; also write a reverse index for sound families
  (`phonetic → [chars]`) either inside `chars.json` or a small `public/dict/families.json`. Keep the total added size
  under ~150 KB. Both are runtime-cached like the shards, not precached.
- Do **not** change `charinfo.gen.json`'s shape or any lesson data (progress keys depend on lesson words).

## Code changes
- `src/views/charsheet.js`:
  - `openChar(c)` becomes async-safe: if `CHARINFO[c]` is missing, build the same `info` shape from `charParts(c)`.
    Show a small loading state only if the fetch takes >150 ms.
  - Every chip gets `data-char`; the global click handler already opens any `[data-char]`.
  - Keep a trail array in the module (reset when the sheet opens from outside the sheet, push when opened from a chip
    inside it). Render it above `.cs-head`. Back/`Esc` pops via the `screen.js` key handling or the dialog's `cancel` event.
  - Sections that need lesson data (mastery badge, "Your words with", Practice writing) only render when relevant;
    for non-lesson chars show "Words with 奂" from CC-CEDICT instead (top 5, tappable to say).
- `src/lib/char-kind.js` (new): `charKind(c, entry)` → `{ kind, text, full?, family? }`.
- Styles: reuse `.cs-chip`, `.lbl`, `.muted`; a trail looks like the existing breadcrumb text style. Must look right in
  all four themes and on iPhone width (no sideways overflow). No new colours.
